# Asteroid City Scope Restorer v2.0.0

Asteroid City Scope Restorer now offers a single restoration: **Theatrical Scope (unmasked)**.

## Changes

- Removed the masked restoration and the restoration-mode menu.
- Simplified setup: select your source MKV and output folder, review the summary, then confirm.
- Fixed a Windows file check that could incorrectly reject valid working files.
- Updated the README for the single restoration.

The unmasked restoration remains unchanged, including its 1920 x 1080 output, processing settings and supported-source check.

If you need the retired masked output, use [v1.0.2](https://github.com/teymourb/Asteroid-City-Scope-Restorer/releases/tag/v1.0.2).

## Download

Download the complete application ZIP and `SHA256SUMS.txt`. Extract the entire ZIP, then run `Asteroid-City-Scope-Restorer.bat`.

GitHub's automatically generated **Source code** downloads are not complete runnable installations.
